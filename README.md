# FutZone

Projeto pessoal de uma loja virtual de camisas de futebol.

Fiz esse projeto para praticar HTML, CSS, JavaScript e também começar a trabalhar com backend usando Python e Flask.

O site possui catálogo de produtos, busca, filtros, ordenação e integração com WhatsApp para fazer o pedido.

No backend, usei Flask para criar uma API que fornece os produtos para o frontend.

## Tecnologias

- HTML
- CSS
- JavaScript
- Python
- Flask

## Funcionalidades

- Catálogo de camisas
- Pesquisa de produtos
- Filtros por categoria e preço
- Ordenação
- Produtos esgotados
- Checkout pelo WhatsApp

## Observação

Projeto feito para estudo e portfólio.

As imagens e marcas utilizadas pertencem aos seus respectivos proprietários.
